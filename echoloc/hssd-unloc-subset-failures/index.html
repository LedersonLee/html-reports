Query 상세로 이동 · 전체 실패 이미지 갤러리

공개 페이지의 RGB는 원본 해상도를 유지한 WebP(quality 70) 표시용 사본입니다. 원본 PNG·모델 입력은 변경하지 않았습니다. Ray·likelihood·집계 수치는 원본과 동일하며 query JSON은 무손실 gzip으로 제공합니다. 화살표 길이는 식별을 위한 표시용이며 실제 거리나 이동량이 아닙니다.

1. 실패 집계

주 지표: XY >1m이면 실패. Joint 실패는 XY >1m 또는 yaw >30°입니다. 같은 물리 위치의 여러 yaw를 별도 query로 세며, 위치 수도 별도로 표시합니다.

2. 세 가지 관찰 태그 — 배타적 원인 분류가 아닙니다

각 태그는 성공·실패 전체에 같은 규칙으로 적용합니다. 한 query에 여러 태그가 붙을 수 있으므로 행의 실패 건수를 더하면 전체 실패 수를 넘을 수 있습니다. Other를 남겨두며 세 범주에 억지로 배정하지 않습니다. Similar layout은 의미적 방 구조가 아니라 11-ray 구조 신호의 유사성입니다.

실패 비율 = 해당 태그의 XY 실패 / 해당 태그 전체 query. 실패 중 점유율 = 해당 태그의 XY 실패 / 전체 XY 실패. CI는 같은 위치의 yaw를 묶은 scene 층화 bootstrap 500회이며, 새로운 scene 일반화 신뢰구간이 아닙니다.

3. 실제로 ray를 못 맞췄는가, 맞춰도 위치를 구별하지 못했는가?

이 표는 관찰된 오차 패턴입니다. 낮은 ray 오차와 유사한 원격 후보가 함께 있으면 ambiguity와 일치하는 증거지만, 이것만으로 인과적 원인을 확정하지는 않습니다. 높은 ray 오차도 반드시 데이터 오류라는 뜻은 아닙니다.

아래 수치는 성공/실패 군의 중앙값입니다. 다른 요인을 통제한 인과 분석은 아니며 scene·같은 위치의 yaw에 의한 상관이 있습니다. Peak gap이 클수록 최고 위치와 1m 밖의 경쟁 위치를 더 잘 구별합니다. 작은 gap은 구별력이 약하다는 뜻입니다.

검토용 예시

각 태그 실패군의 중앙 XY 오차에 가까운 사례를 scene별로 선택했습니다. 통계적 대표 표본 또는 사람이 확인한 정답 원인 라벨은 아닙니다.

재현·해석 범위
원본 heatmap의 vision 채널을 그대로 사용했습니다. 모든 1,472개 query의 MAP를 원본 예측 depth와 DESDF로 다시 계산하여 기존 결과와 일치시켰습니다. 기존 실험 DESDF 거리 상한 10m를 그대로 유지했으며 25m 실험과 혼합하지 않았습니다. GT 최근접 후보는 실제 GT와 최대 grid 양자화 오차가 있으므로 40-column 학습 GT와 구별해서 표시합니다. 일반적인 가구 가림, 문·유리, 기존 false-closed/ambiguous 플래그는 자동으로 데이터 오류나 제외 사유로 간주하지 않습니다.
